# Módulo 06: Evolución Clínica

## Descripción
Módulo para registrar las actividades realizadas durante cada consulta del paciente.

## Responsable
Dev 6

## Funcionalidades
- Registrar fecha de atención
- Registrar motivo de consulta y procedimiento realizado
- Asociar pieza dental y diagnóstico
- Registrar observaciones e indicaciones
- Registrar próxima atención
- Consultar evolución cronológica
- Asociar evolución a plan de tratamiento

## Tablas relacionadas
- `evoluciones_clinicas` - Registro de cada atención

## Dependencias
- Módulo 02 (Pacientes) completado
- Módulo 05 (Diagnóstico/Tratamiento) recomendado
- Tabla `evoluciones_clinicas` creada
