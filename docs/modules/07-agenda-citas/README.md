# Módulo 07: Agenda y Citas

## Descripción
Módulo para gestionar las citas y disponibilidad de los profesionales odontológicos.

## Responsable
Dev 1

## Funcionalidades
- El odontólogo carga su disponibilidad horaria
- Pacientes eligen citas de los horarios disponibles
- Visualizar calendario (diario, semanal, mensual)
- Reprogramar y cancelar citas
- Registrar horas no disponibles *(VERSIÓN 2 - fuera del MVP)*
- Estados: RESERVADA → CONFIRMADA → ATENDIDA / CANCELADA

## Tablas relacionadas
- `horarios` - Disponibilidad del odontólogo
- `citas` - Citas agendadas

## Dependencias
- Módulo 01 (Auth) completado
- Módulo 02 (Pacientes) recomendado
- Tablas de horarios y citas creadas
