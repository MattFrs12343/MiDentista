# Módulo 12: Gestión de Clínica

## Descripción
Módulo para administrar la información general de la clínica: profesionales, especialidades, consultorios y servicios.

## Responsable
Dev 6

## Funcionalidades
- Registrar información de la clínica (nombre, dirección, logo)
- Registrar profesionales con información profesional
- Registrar especialidades
- Registrar consultorios
- Configurar horarios generales
- Gestionar servicios con precios

## Tablas relacionadas
- `clinicas` - Datos de la clínica
- `especialidades` - Catálogo de especialidades
- `servicios` - Catálogo de servicios con precios
- `consultorios` - Consultorios disponibles

## Dependencias
- Módulo 01 (Auth) completado
- Tablas de clínica, especialidades, servicios y consultorios creadas
