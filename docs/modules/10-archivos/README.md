# Módulo 10: Archivos e Imágenes

## Descripción
Módulo para almacenar y consultar documentos, fotografías y radiografías relacionadas con los pacientes.

## Responsable
Dev 4

## Funcionalidades
- Subir fotografías clínicas (JPG, PNG)
- Subir radiografías
- Subir documentos PDF
- Asociar archivos a paciente, consulta o tratamiento
- Visualizar archivos en navegador
- Descargar archivos
- Límite: 5 GB por clínica

## Tablas relacionadas
- `archivos` - Registro de archivos subidos

## Dependencias
- Módulo 02 (Pacientes) completado
- Supabase Storage configurado
- Tabla `archivos` creada
