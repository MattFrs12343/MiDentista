# Módulo 03: Historia Clínica

## Descripción
Módulo para centralizar la información clínica y odontológica del paciente.

## Responsable
Dev 3

## Funcionalidades
- Registrar motivo de consulta
- Registrar antecedentes médicos y odontológicos
- Registrar alergias, medicamentos, enfermedades, hábitos
- Consultar información clínica
- Actualizar información clínica
- Ver historial de cambios

## Tablas relacionadas
- `historiales_clinicos` - Datos clínicos del paciente

## Dependencias
- Módulo 02 (Pacientes) completado
- Tabla `historiales_clinicos` creada
