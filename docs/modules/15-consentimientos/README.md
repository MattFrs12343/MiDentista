# Módulo 15: Consentimientos

## Descripción
Módulo para gestionar documentos de consentimiento informado y autorizaciones del paciente.

## Responsable
Dev 3

## Funcionalidades
- Crear plantillas de consentimiento
- Registrar consentimiento informado
- Asociar consentimiento a tratamientos
- Checkbox de aceptación del paciente
- Registrar fecha de aceptación
- Consultar consentimientos
- Vincular consentimiento a plan de tratamiento

## Tabla relacionada
- `consentimientos` - Consentimientos registrados

## Dependencias
- Módulo 02 (Pacientes) completado
- Módulo 05 (Tratamiento) recomendado
- Tabla `consentimientos` creada
