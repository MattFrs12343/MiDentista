# Módulo 14: Configuración de Clínica

## Descripción
Módulo para adaptar el sistema a las características particulares de cada clínica.

## Responsable
Dev 2

## Funcionalidades
- Configurar datos generales de la clínica
- Configurar moneda
- Configurar servicios y precios
- Configurar horarios
- Configurar métodos de pago
- Configurar estados de tratamientos personalizados
- Configurar parámetros generales

## Tabla relacionada
- `configuracion_clinica` - Configuraciones clave-valor

## Dependencias
- Módulo 12 (Gestión de Clínica) completado
- Tabla `configuracion_clinica` creada
