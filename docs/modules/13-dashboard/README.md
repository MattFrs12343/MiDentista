# Módulo 13: Dashboard

## Descripción
Módulo para mostrar información resumida y relevante según el rol del usuario.

## Responsable
Dev 1

## Funcionalidades
**Dashboard del super-admin:**
- Resumen de todas las clínicas del sistema

**Dashboard del recepcionista:**
- Citas del día
- Pacientes del día
- Pagos pendientes

**Dashboard del odontólogo:**
- Citas del día
- Pacientes atendidos
- Tratamientos activos/pendientes
- Próxima actividad

**Dashboard del paciente:**
- Próxima cita
- Tratamiento actual
- Pagos pendientes
- Documentos disponibles

## Dependencias
- Módulos 02, 07, 09 recomendados para datos del dashboard
